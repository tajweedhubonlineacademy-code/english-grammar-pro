# 🚀 GrammarCraft VIP - Modern English Grammar & Live Translator

An ultra-premium, mobile-first, zero-database English Grammar web application designed for students and learners, featuring instant Urdu translations, audio pronunciation, and interactive quizzes.

---

## ✨ VIP Features Included

1. **Smart Live Translator (Urdu ⇄ English)**:
   - Instant live translation as you type.
   - 1-click language swap.
   - Text-to-Speech audio pronunciation speaker (British/American accent).
   - Copy to clipboard with toast notification.
   - Sample quick phrase chips.

2. **All 12 Tenses Master Guide**:
   - Present, Past, and Future Tenses with category filter pills.
   - Urdu identification (*پہچان*), Helping Verbs, and Main Verb forms.
   - Positive, Negative, and Interrogative formulas.
   - Everyday practical example sentences with audio buttons.

3. **8 Parts of Speech (اجزائے کلام)**:
   - Noun, Pronoun, Verb, Adjective, Adverb, Preposition, Conjunction, Interjection.
   - Modern cards with colored accents, Urdu descriptions, core types, and usage examples.

4. **Active & Passive Voice + Direct & Indirect Speech**:
   - Complete side-by-side comparative formula chart.
   - Pronoun conversion rules (*SON Formula*).
   - Real-life sentence transformations with audio.

5. **Common Mistakes & Sentence Corrections**:
   - Visual "Don't Say ❌ vs Say ✅" comparison pills.
   - Urdu explanations and reasons for the corrections.

6. **Interactive Quiz Arena**:
   - Dynamic 10-question MCQ quiz with Urdu hints.
   - Instant visual green/red feedback with full explanations.
   - Progress bar and final percentage score report.

7. **VIP UX & Polish**:
   - **Dark Mode & Light Mode** with 1-click persistence.
   - **Live Instant Search Bar** across all grammar topics.
   - **Mobile Drawer Navigation** for 100% responsiveness on phones, tablets, and laptops.
   - Zero database required, zero monthly hosting costs.

## ⚡ How to Deploy on Vercel (Free & Instant)

### Method 1: Using Vercel Dashboard (Easiest - Drag & Drop or GitHub)
1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **"Add New Project"**.
3. Push this `english-grammar-pro` folder to a GitHub repository and click **Import**, OR install the Vercel CLI.
4. Framework Preset: Choose **"Other"**.
5. Root Directory: `./`
6. Click **"Deploy"**! In 10 seconds, you will receive a live URL (e.g. `https://your-grammar-app.vercel.app`).

### Method 2: Using Vercel CLI
Open terminal in `english-grammar-pro` folder and run:
```bash
npx vercel
```
Follow the simple prompts (press Enter for defaults) and it will deploy instantly!
